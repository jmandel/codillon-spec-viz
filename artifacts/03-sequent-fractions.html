3 · Sequent fractions — hypotheses over conclusions

Codillon already draws each instruction's stack effect as a fraction: input cups above a rule, outputs below. This prototype reads that fraction as a sequent. Above the rule sit the facts known about the inputs at this point (tiny iconic predicate chips attached to the cup they describe, plus named context cups for locals the obligation mentions); below the rule sit the facts the refined type claims about the outputs. The rule itself is the verdict: a quiet solid rule when the claim follows; dashed indigo with a mystery star when the checker cannot tell; dotted slate when only this run's checks held; and snapped into two offset darkred halves when a counterexample exists, with the counterexample's values written inside the shapes exactly where runtime values go. A fact that was needed but missing appears as Codillon's empty fade-up cup, now holding the absent fact. Thin proof wires run from a sequent's chips back to the lines that supplied them (the checker's unsat core), so "why" is a curve you can follow, like dataflow. Compound predicates are split into one chip per conjunct, each with its own status. Click any sequent to pin its wires; click a darkred mark to jump to its witness.
