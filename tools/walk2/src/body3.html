4 · Lesson 2 · integer square root

$isqrt counts r up while (r+1)² ≤ n. The spec has two parts, and neither is an annotation. The result type says $is_isqrt(r, n). That is an ordinary i64 Wasm function computing r² ≤ n < (r+1)², in i64 so that the check itself cannot overflow. The harness calls $isqrt, runs the same predicate, and skips unreachable when the check passes.

  1. The loop invariant is the loop’s type. loop $grow (fact (call $sq_le …)) on line 34 holds on entry (line 33, prove 0, from r = 0), and the back-edge must supply it again (line 59).
  2. A refined local is a second invariant. (local $r (i32 | (i32.le_u v 65535))) keeps every square linear in a monomial atom and inside i64. The cost is the early exit at 65535.
  3. unreachable consumes False. The harness’s prove 2 on line 73 takes the call’s result fact and the fall-through fact “the check failed”. Together they contradict each other, so the step derives False and the ⊥ cup on line 74 is proven. That proof is the theorem: for every n, $isqrt(n) is the integer square root.
