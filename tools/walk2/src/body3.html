5 · Lesson 2 · integer square root

$isqrt counts r up while (r+1)² ≤ n. The spec has two parts, and neither is an annotation. The result type says $is_isqrt(r, n). That is an ordinary i64 Wasm function computing r² ≤ n < (r+1)², in i64 so that the check itself cannot overflow. The harness calls $isqrt, runs the same predicate, and skips unreachable when the check passes.

  1. The loop invariant is the loop’s type. loop $grow (fact (call $sq_le …)) on line 33 must hold on entry, where r = 0 (its label: “needs sq_le(0, n) ✓ true for every value”). The back-edge on line 55 must supply it again.
  2. A refined local is a second invariant. (local $r (i32 | (i32.le_u v 65535))) keeps every square linear in a monomial atom and inside i64. The cost is the early exit at 65535.
  3. unreachable consumes False. In the harness, the call’s result fact (line 62) and the fall-through fact “the check failed” (line 67) contradict each other. The kernel finds that, and the ⊥ cup on line 68 is labelled “the facts of lines 62, 67 contradict each other: this line never runs”. That proof is the theorem: for every n, $isqrt(n) is the integer square root.
