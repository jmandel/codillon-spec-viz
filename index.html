Codillon with refinement types

A visualization study: when types carry predicates, how should the editor draw whether a program meets its specification?

Codillon is Keith Winstein's structured WebAssembly editor for Stanford's intro course. Today it shows validity continuously and spatially: types are shapes, dataflow is curves, badness is dark red, and runtime is a slider. This study asks what a next version would look like if types were refinement types grounded Lean‑style ((i32 | even v), loop invariants, function contracts, a hash table's representation invariant) and the editor had to make a specification‑adherence bug as visually obvious as a type error is today.

Ten prototypes

Each page follows the same contract: legend → primitive in isolation → integer square root (or gcd) with a step slider and a “seed bug” control → an 8‑slot open‑addressing hash table with the same → self‑critique. Everything is a single self‑contained HTML file.

01
Shape as value space

The i32 rectangle is the number line; a refinement is a region inside it; a failed subtyping check spills over the cup's rim.

02
Wraparound ring

i32 as a clock with a seam; overflow is a bead jumping the seam; signed and unsigned readings as twin ticks.

03
Sequent fractions

Codillon's type fraction becomes a sequent: known facts above the rule, claimed facts below; the rule's style is the obligation's status.

04
Fact ribbons

Dataflow curves carry stripes of facts that are born, preserved, or fray out where an operation loses them.

05
Invariant horizon

A gate on the loop frame; a lap chart of invariant conjuncts per iteration; a descending staircase for termination.

06
Model / memory mirror

Abstract map above, concrete slots below, strings between them; the representation invariant is a clean alignment.

07
Witness track

Counterexamples are runs: a ghost track above the slider, replayed into a dark‑red pill, with the false sub‑term underlined.

08
Spec sampler

Relation plots and edge‑case grids: sampled calls drawn on the spec's own shape; coverage, not proof.

09
Envelope strips

Per‑variable timelines under the slider; the refinement is a band, the value a line, a violation the line leaving the band.

10
Synthetic proof holes

An undischarged obligation materializes as an inserted hole line, like a synthetic end, with suggestion chips.
